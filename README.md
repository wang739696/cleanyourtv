# cleanyourtv
cleanyourtv手机管理端
CleanYourTV管理器是一个运行在安卓手机上的App，通过局域网里的 ADB连接你的安卓电视或盒子，在手机上完成原本要拿遥控器、插U盘或接电脑才能做的事。

使用方法：

1.下载cleanyourtv安卓管理器

https://pan.quark.cn/s/d4e0c342d4a5 

不需要 root，也不需要把手机连电脑。

手机和电视在同一个局域网，电视打开网络调试（ADB）即可。

首次连接时电视会弹出调试授权，点允许后以后不再询问。（需要返回电视桌面才能看到授权弹窗）
